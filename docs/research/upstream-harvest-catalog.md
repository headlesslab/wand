### Baseline scope used for classification

From the wand map (#1) as relayed by the task: the baseline release = **rename the module, fix dependencies, regenerate the CDP protocol, update browser fetching, fix Chrome >= 136 breakage, harvest upstream bug fixes; no API redesign.**

- **harvest into baseline**: a bug fix, dependency fix, or platform/browser-compat fix that does not change or add public API (or changes it only in a way the rename already forces).
- **defer to API modernization**: adds or changes public API surface, or is a feature/redesign.
- **drop**: superseded by another PR, out of scope for a CDP driver, or the change is undesirable as written.

# wand

Go 语言的 Chrome DevTools Protocol 驱动，用于浏览器自动化与网页抓取。

wand 源自 [go-rod](https://github.com/go-rod/rod) 的一份代码快照（提交 `393ac0d`，2024-12-07），由 headlesslab 独立维护。署名信息见 [NOTICE](NOTICE)。
